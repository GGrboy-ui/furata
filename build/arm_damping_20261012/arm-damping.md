# 转臂速度阻尼

2026-10-12：平衡状态（K3 手动平衡或 K1 起摆捕获后）新增独立的转臂速度阻尼。

每个角度环周期采集经 `ENCODER_INVERT` 修正方向后的编码器位置。默认周期为 5 ms：

```text
delta = position[k] - position[k-1]           // counts / 5 ms
damping = clamp(delta * ARM_DAMPING_KD / 65536, -limit, +limit)
command = clamp(angle_PID - damping, -100%, +100%)
```

`angle_PID` 包含原位置环对目标角度的修正。速度阻尼直接修正 PWM 要求值，不替代位置环，也不会单独保持转臂位置。正位置增量产生负 PWM 修正；物理电机方向仍由 `MOTOR_INVERT` 转换。实机上正控制输出必须对应正编码器位置运动，否则需先核对方向配置。

在 `src/board/acg720_top.v` 调整以下综合参数，并重新编译下载：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `ARM_DAMPING_KD` | `65536` | Q16.16 增益，默认每个窗口移动 1 count 修正 1 个 PWM 百分点；`32768` 为 0.5，`0` 关闭 |
| `ARM_DAMPING_LIMIT_PERCENT` | `20` | 阻尼项单独限制在 ±20 个 PWM 百分点；有效范围 0～100 |

负增益按零处理，限幅参数钳在 0～100。内部保留小数，不在乘法前取整。例如增益 32768、位移 3 count 对应 1.5% 修正。默认 5 ms 时，1 count/window 等效 200 counts/s，默认增益等效 0.005 PWM 百分点/(count/s)。若更改核心 `ANGLE_MS`，需要按窗口长度重新选择增益；代码不会自动换算。

该实现使用窗口位移，不使用现有编码器 `vel` 周期测速输出，避免停车后沿用上一次非零速度直至其超时。一个完整窗口无位移后阻尼归零；低速下存在单计数脉冲，这是窗口差分的量化特性，默认每个计数为 1% 修正，未额外低通。默认值是调试初值，尚未通过实机整定。

停止、失去许可、故障、K4 复位和系统复位均清除阻尼状态。进入平衡前持续更新位置基准，避免捕获原点造成速度冲击；使用未被相对位置限幅的计数做模减法，允许编码器计数跨过 32 位边界。采样后的下一个系统时钟同时更新角度 PID 和阻尼，再以 33 位减法合成并限幅。起摆脉冲、等待捕获、K2 固定 PWM 试转不叠加阻尼。串口要求 PWM 会自然包含阻尼修正，回传协议不变。
