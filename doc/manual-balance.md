# K3 手动扶直后维持平衡

更新：2026-10-10。实际工程为 `G:/furata/furata/furata.gprj`。

用户选择：先把摆杆扶到直立附近，再按 K3 直接进入平衡控制，用于单独调试平衡。

1. 下载新生成的 `impl/pnr/furata.fs`。按 K4，确认无故障且显示 `00`。
2. 将摆杆扶到直立附近，确认传感器读数。当前控制中心为 ADC 1011；沿用原窗口，允许整数读数 512～1510。
3. 按 K3，满足采样就绪、许可和角度条件时直接显示 `40`。记录当前转臂位置作为零点，角度环每 5 ms 更新，位置环每 50 ms 更新，持续保持平衡目标和进入时的转臂位置。
4. 电驱仍先使能并等待 2 ms，再开放 PWM。该启动没有 PUSH/PULL 起摆脉冲；后续 PWM 由平衡 PID 的误差决定。
5. 按 K4 或串口 `X` 停止。角度越界、位置越界和传感器异常仍锁存故障并关断。

K3 不再发送 -10° 位置指令。在起摆、试转、平衡或故障状态按 K3 不改变模式、不重置位置原点、不清除故障。角度在窗口外或传感器未就绪时忽略 K3；之后角度进入窗口也不会自动启动，需要松开后重新按 K3。K4 的优先级高于 K3，长按 K3 不会在 K4 复位后自动重启。

保留现有角度和位置 PID 参数、反馈方向、PWM 渐变、换向等待、用户当前中心 1011 与起摆 45% / 120 ms。K3 将起摆过程与平衡调试分开；显示 `40` 代表平衡控制已运行，机械稳定性仍需实物验证。

专项测试 `sim/tb_acg720_manual_balance.v` 使用合成角度与编码器数据，检查启动条件、拒绝请求不排队、直接切入且无起摆脉冲、位置原点、双向角度响应及电机方向输出、位置环保持、重复 K3、长按与 K4、运行中忽略、串口停止、角度/位置/传感器故障及恢复。既有角度显示测试显式使用历史 1014 标定样例，控制测试显式使用 35% 样例，避免测试随用户调参改变其验证含义。
