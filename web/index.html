按 K1 起摆或 K3 进入位置环平衡后执行轨迹。FPGA 每 1 ms 生成连续位置目标，由位置 PID 跟踪，角度内环保持平衡。参考速度是位置曲线的导数，用于与编码器实际速度对照。所有角度相对本次启动位置；正值沿用顺时针约定。

等待实际外环回读

轨迹使用位置环，不需要按 K2。若已切到速度环，先 X/K4 停机，再按 K1/K3 返回位置平衡。轨迹用时建议 10～20 s；360°等大角度会按板端限速自动延长推荐用时。位置 PID 更新周期仍独立设置，默认 50 ms。

使用说明

USB 串口默认 115200 / 8N1。P 开始回传，Q 仅停止回传；X 或实体 K4 停机。轨迹或等待到位期间拒绝新任务和周期修改。断开不会自动恢复任务。

数据来源

规划预览与板端参考均不是实测。角度来自原遥测；速度跟踪采用板端闭环测速，另列最近 200 ms 的位置拟合速度作为对照。状态回复会占用遥测带宽，序号缺口保持可见。
