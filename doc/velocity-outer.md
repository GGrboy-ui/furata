# 位置／速度双外环（VEL1，2026-10-31）

工程：`G:/furata-git/furata`。运行本工程 `web/start.cmd`，以终端打印的网址为准。默认端口 8766，若被旧工程占用会选择下一空闲端口；本次验证地址为 `http://localhost:8767/`。页面顶部应显示“VEL2 / 位置启动”，速度调参位于轨迹区顶部。

## 使用

1. 使用本次发布包匹配的 `.fs` 与网页。连接后识别 TRJ1 和 VEL1；未识别 VEL1 时，新设置保持禁用。
2. 上电默认“位置外环”，不自动进入速度环。位置环周期 50 ms，预置速度周期 20 ms。停机时在网页填写速度周期、Kp、Ki、Kpos，点击“应用参数并进入速度环”，网页发送 `@TVC` 整组参数，等待板端回读明确显示“速度外环”。可用“应用参数并返回位置环”恢复定位模式。
3. 确认速度模式后，实体 K3 从直立窗口内进入平衡，再执行四种轨迹。网页和 FPGA 都拒绝位置模式下的轨迹启动；普通 ARM1 相对转动可在任一外环运行。运行及平衡空闲均禁止修改新增设置。
4. X/K4 停机并清除控制历史，保留所选模式与速度参数；系统复位／重新上电恢复位置外环和默认速度参数。网页重连只查询，不重发配置、不恢复运动。
5. 下载文件不自动烧录。本次数字验证不代表实物平衡或轨迹误差验证；以下增益是待实物调整的起始值。

## 控制结构与单位

位置模式保留原位置 PID → 角度 PID；速度模式为：

```
v_correction = clamp(Kpos * (p_ref - p_actual), ±5°/s)
v_target = clamp(v_reference + v_correction, ±30°/s)
e_v = v_target - v_actual
angle_correction = clamp(Kp*e_v + integral(Ki*e_v*dt), ±24 ADC codes)
angle_target = CENTER - angle_correction
```

位置、速度和角度修正均为带符号 Q16.16；速度单位 counts/s，位置单位编码器 counts。
Kp 单位 ADC/(count/s)，Ki 单位 ADC/count，Kpos 单位 1/s。
默认整数 Kp=6554、Ki=1311、Kpos=32768，即约 0.1000061、0.0200043、0.5。
速度 PI 按实际周期乘 dt/1000，积分贡献限 ±24 ADC，向外饱和时停止增加积分。
位置修正、总速度限按 COUNTS_PER_REV 换算；默认 408 counts/圈。方向沿用 ENCODER_INVERT/CW_POSITIVE/MOTOR_INVERT。
角度中心、角度 PID、PWM、独立平衡补偿及保护沿用当前工作代码。

位置 PID 与速度 PI 独立，仅选中者驱动角度内环，未选中的外环保持清除。
停止、退出平衡、保护或模式改变均清除外环历史。角度环仍为 5 ms。
原位置环周期设置单独保留；速度模式下原周期握手仍能在其名义边界完成，避免配置请求挂起。
位置环原离散 KI/KD 不按周期自动换算。

轨迹已有的位置／速度一起使用；普通 ARM1 目标斜坡输出每个实际增量乘 1000，末段按剩余增量计算速度。
轨迹停留、终点等待和完成保持均以零参考速度继续位置修正。连续累计位置不取模，原 ±10 圈保护和连续 200 ms、误差 ≤2 counts 到位规则保留。

## 编码器测速

旧 `encoder_qei.vel` 输出不变。新增 `control_velocity_q` 是 Q16.16 counts/s，顶层以 1 ms tick 驱动。
仅相邻有效正交跳变参与测速。启动、超时后的首边沿及反向首边沿只建立新方向基准；第二个同向边沿建立周期。
速度幅值为 `CLK_HZ*65536/max(last_period,edge_age)`，因此迟迟无新边沿时估计递减，不保持旧速度整整一秒；满 1 秒直接归零。
以 1 ms 更新 `v += (raw-v)/40`，约 40 ms 低通。硬件以精确有符号倒数乘法替代组合除法，并分两级寄存，额外两个系统时钟延迟远小于 1 ms。反向、超时及复位取消待完成除法，清除滤波历史。
低速时仍受编码器分辨率及等待边沿限制；显示保留原最近 200 ms 位置线性拟合速度作为独立对照。

## 串口扩展

沿用 115200、8N1、ASCII 请求、LF/CRLF 结尾，行长／超时和 X 优先规则不变。新增请求均路由到原轨迹协议模块：

```
@TVI                                  查询 VEL1 能力
@TVQ                                  查询实际配置及控制反馈
@TVC,id,outer,period_ms,kp_q,ki_q,kpos_q 停机时原子设置整组参数
@TVC,1,1,20,6554,1311,32768            网页进入速度模式
@TVC,2,0,20,6554,1311,32768            切换到原位置外环
```

id=1..65535；outer=0 位置、1 速度；period=5..100 ms；Kp/Ki 的 Q16.16 整数范围 0..1048576（0..16），Kpos 为 0..655360（0..10）。零增益允许；超界整组拒绝。只允许 STOP 且无故障／运动／周期待处理／同时启动事件时设置。
回复大写定长十六进制，CRLF：

```
@I,VEL1,0014,0005,0064
@V,id4,code2,state1,outer1,period4,kp8,ki8,kpos8,reference8,target8,actual8,angle_offset8,active_id4,elapsed8
```

能力 24 字节，状态 98 字节。速度 reference/target/actual 为有符号 Q16.16 counts/s；angle_offset 为实际送入角度目标的有符号 Q16.16 ADC 修正，等于 angle_target-CENTER。
code=04 设置生效、11 状态不允许、12 参数超界；查询带最近设置编号及结果。首次查询 code=00/id=0。格式错误仍沿用原 TRJ1 的 13 错误回复。
反馈帧在发送前统一快照；elapsed/active_id 是任务状态采样标记，速度 PI/编码器本身分别按其周期更新，不宣称为完全同步的全量采样。
查询独立限速 200 ms，网页按 250 ms 请求任务及速度状态；回复只在完整帧之间发送，普通遥测可出现可识别的序号缺口。
TRJ1/ARM1/普通 T 遥测及普通 CSV 格式不变。
