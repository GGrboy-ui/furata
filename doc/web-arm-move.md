# 网页自定义转臂角度（ARM1）

工程：`G:\furata-git\furata`，更新日期：2026-10-29。

## 使用

1. 将本次独立构建的 `furata.fs` 下载到 ACG720。旧固件没有 ARM1 功能，网页不会开放转动按钮。本次未自动烧录。
2. 运行工程 `web\start.cmd`，用桌面 Chrome / Edge 打开 `http://localhost:8766`。连接板卡串口，默认 115200 / 8N1。
3. 网页应显示 `ARM1 · 408 counts/圈 · 30°/秒`。停机时扶摆杆到直立窗口，使用实体 K3 进入平衡；网页板端状态应为“直立平衡 · 空闲”。
4. 在“转动角度（°）”自行输入 `+60`，点击“执行转动”。等到“已到位，保持目标位置”后，再输入 `-40` 执行。第二次以接受指令时的实际位置为起点；若第一次实际到达 +60°，两次后约为起点 +20°。
5. 也可输入 `12.5`、`-90` 等。最多一位小数，单次 −3600.0°～+3600.0°；0° 不产生移动。正值沿用工程 CW_POSITIVE 定义为顺时针，负值逆时针。实机须核对安装方向。
6. 移动时仍使用原位置环和角度环保持直立。网页禁用新移动，板端也拒绝新的移动请求。可随时点击“立即停机 X”或按实体 K4。

目标按 30°/秒渐变，而非把电机直接切换为固定 PWM。轨迹到终点且实测误差连续 200 ms 不超过 2 counts 才判定到位；408 counts/圈时约为 ±1.76°。输入的 0.1° 是指令分辨率，不是实物定位精度。移动结束后保持目标，后续漂移会由位置环继续纠正。

只有 BALANCE、传感器正常且无故障时才接受命令。以本次进入平衡时捕获的位置为固定行程原点，目标必须在 ±4080 counts（±10 圈）内；超界整条拒绝，不截短。运动中超行程、失去平衡或故障沿用原保护并取消移动。若一直未满足到位条件，保持忙状态；可用 X/K4 停机，不会自动宣布到位或执行下一条。

“开始回传 P / 停止回传 Q”仍只控制遥测。ARM1 能力/状态查询不改变电机状态。主动断开时，若存在进行中或结果不确定的移动，先发 X 再发 Q。串口突然拔出时不能保证 X 送达；板端继续执行已接受的目标及原有本地保护，必要时使用实体 K4。

2026-10-30：新增 TRJ1 四种轨迹与位置环周期设置，普通 ARM1 与 TRJ1 共享运动忙状态。详见 [轨迹说明](trajectory-control.md)。

## 串口接口

请求是 ASCII 完整行，LF 或 CRLF 结束：

```text
@I\n                  查询 ARM1 能力
@Q\n                  查询最近接受的移动结果与当前状态
@M,17,+600\n          编号17，相对当前实际位置顺时针60.0°
@M,18,-400\n          编号18，相对当前实际位置逆时针40.0°
X                     单字节立即停机，包括残缺命令中收到X
```

请求编号为十进制 1～65535；角度为必须带正负号的十进制整数，单位 0.1°，绝对值不超过 36000。命令整行须在 200 ms 内完成、长度不超过 32 字节；格式、溢出或超时失败不产生运动。符号前不接受空格；网页负责把用户输入的小数角度转换为协议整数。重复最近一次接受的编号不重复执行；网页不自动重发移动指令。页面重新连接后从板端最近编号继续递增。

能力回复：

```text
@I,ARM1,0198,001E,0FF0\r\n
```

三个数均为四位十六进制：每圈计数 408、速度 30°/秒、行程半宽 4080 counts。

状态/事件回复固定 34 字节：

```text
@R,0011,01,4,1,00000000,00440000\r\n
```

依次为编号（四位十六进制）、结果码（两位十六进制）、控制状态、忙标志、实际累计位置（八位补码整数 counts）、最终目标（八位补码 Q16.16 counts）。示例表示编号17已接受，BALANCE，执行中，实际位置0，目标68 counts即60°。

| 结果码 | 含义 |
|---|---|
| 00 | 尚无接受的移动，当前状态 |
| 01 | 已接受 |
| 02 | 已到位（或0°无需移动） |
| 03 | 停机/故障/失去允许条件，已取消 |
| 10 | 忙，拒绝新命令 |
| 11 | 非正常平衡状态，拒绝 |
| 12 | 新目标超行程，拒绝 |
| 13 | 命令格式、范围编码或接收时限错误 |
| 14 | 最近接受的编号重复，拒绝重复执行 |

接受、完成和取消会主动回复。`@Q` 返回最近接受的编号及其结果，附实时状态、忙标志、位置和目标；被拒绝的请求不覆盖最近已接受移动的查询结果。若上位机洪泛请求，待发报告可以合并，查询可恢复最近已接受移动的结果；因此不能把查询超时解释为允许重新发送运动命令。

回复仅在完整 T 帧间发送，回复期间必要时跳过遥测期限，保留序号缺口。55字节 T 帧、CSV和P/Q语义不变。ARM1 顶层关闭单字节回显，避免回显破坏回复行；S/X/C/D/A/P/Q指令功能保留，完整帧内部的字节不会触发旧指令，X例外。
