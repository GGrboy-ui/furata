# K1 位置平衡、K2 速度环与独立 PID（2026-10-31）

## 操作

工程 `G:/furata-git/furata/furata.gprj`；网页运行 `web/start.cmd`，以打印地址为准。本机当前为 http://localhost:8767/，旧 8765/8766 指向其他目录。页面标识 POS1 + VEL3，新增源文件后需在高云重新打开工程，确认 `outer_handover.v` 和 `pwm_friction.v` 均在设计文件列表内。

1. 停机连接串口，识别 POS1、VEL3。网页位置 PID 和速度 PID 是独立参数组，可以先编辑草稿；只有停机、无故障且无待处理运动／设置时允许下发。
2. K1 起摆，自动进入位置外环平衡；K3 保留直立窗口内手动进入位置平衡。每次有效 K1/K3 都强制位置模式，即使上次停止前使用速度模式。
3. 平衡空闲时按 K2，保留原位置目标、累计坐标和保护基准，经过 200 个实际毫秒节拍后完全进入速度环。网页显示当前模式和交接剩余时间；交接期间不能开始轨迹或普通移动。
4. K2 在停机、起摆、故障或运动任务执行中无动作，不排队；重复按 K2 不切回、不重新交接。原 K2 开环电机测试入口取消。网页不发送模式切换命令。
5. X/K4 即时停机并中断交接，保留两套参数及上次模式记录；下次 K1/K3 仍进入位置模式。系统复位／上电恢复参数默认值和位置模式。网页重连只查询，不应用草稿、不重发运动。

## 两组参数与单位

| 参数 | 位置外环 | 速度外环 |
|---|---|---|
| 默认 Kp / Ki / Kd（Q16.16 整数） | 39214 / 400 / 362144 | 6554 / 1311 / 0 |
| 默认十进制 | 0.5983581543 / 0.0061035156 / 5.5258789063 | 0.1000061035 / 0.0200042725 / 0 |
| 增益范围 | 各 0～64 | 各 0～16 |
| 周期 | 1～1000 ms，默认 50 | 5～100 ms，默认 20 |
| 时间约定 | 保留原离散 PID，每次更新计算，不自动换算 Ki/Kd | I、D 按实际周期换算秒 |
| 附加参数 | 无 | Kpos=0.5/s（0～10），t=0（0～PWM_MAX） |
| 输出限幅 | 保留原 ±100 ADC 码 | ±24 ADC 码 |

角度内环仍为原 5 ms PID，参数和标定不由这两个网页参数区修改。位置运行时默认值取自同一份控制核心编译参数；位置积分死区／衰减语义保留。

速度模式保持 `v_target=clamp(v_ref+clamp(Kpos*位置误差, ±5°/s), ±30°/s)`。速度 Kp 单位 ADC/(count/s)，Ki 单位 ADC/count，Kd 单位 ADC/(count/s²)。其 D 为实际速度的负微分：

```
a_raw = saturate((v_actual - v_previous) * 1000 / period_ms)
a_filtered = saturate(a_filtered + (a_raw - a_filtered) * period_ms / (40 + period_ms))
u_speed = clamp(Kp*(v_target-v_actual) + integral(Ki*error*dt) - Kd*a_filtered, ±24 ADC)
```

首样本微分为零，D 采用固定 40 ms 低通，不对目标速度求微分；Kd=0 保持 PI 行为。积分按 P+I-D 的总输出进行抗饱和。计算采用宽位运算、饱和和顺序除法。

位置和速度的参数、周期、积分／微分历史、请求编号及回读分别保存。位置设置不能改变速度参数，速度设置不能改变位置参数。t 仅在速度模式按控制方向叠加 PWM 计数；单独应用 t 使用板端当前速度 PID，不使用其他尚未提交的输入框值。

## 200 ms 交接

K2 接受时捕获位置环最后输出，清除两个外环历史，保留角度内环历史。随后每个 1 ms 节拍更新位置快照与当前速度 PID 输出的线性权重，200 ms 后完全交给速度环；t 同步从 0 渐增。过渡可以继承原位置输出的合法幅度，速度 PID 自身始终限幅 ±24 ADC，过渡结束后实际修正完全受该限幅约束。X、K4、故障、退出平衡立即取消计算和交接，原电机缓升及换向保护继续有效。

## 串口

115200 / 8N1，ASCII 十进制请求，LF 或 CRLF。增益传输 Q16.16 非负整数。编号 1～65535，零增益有效。整包参数错误、运行中设置及模式字段不一致均不部分生效。

```
@TPI                                     位置参数能力
@TPQ                                     位置参数查询
@TPC,id,period_ms,kp_q,ki_q,kd_q            原子设置位置组
@TV3                                     速度 PID 能力
@TVS                                     速度 PID / 模式 / 交接查询
@TVE,id,period_ms,kp_q,ki_q,kd_q,kpos_q,t    原子设置速度组
```

能力：`@I,POS1`（9 字节含 CRLF），`@I,VEL3,0014,0005,0064,09C4`（29 字节；最后为 PWM_MAX 的十六进制）。查询／设置回复为不可变快照，大写固定宽度十六进制：

```
@P,id4,code2,state1,period4,kp8,ki8,kd8
@W,id4,code2,state1,outer1,remaining_ms4,period4,kp8,ki8,kd8,kpos8,t4,reference8,target8,actual8,angle_offset8,active_id4,elapsed8
```

@P 为 46 字节，@W 为 117 字节（含 CRLF）；速度和角度偏移为带符号 Q16.16。outer=0 位置、1 速度；停机时是上次模式记录，并不驱动电机。结果码 04 生效、11 当前状态不允许、12 参数越界。查询带对应组最近设置编号和结果，两组同编号不会互相确认。

旧 @TVI/@TV2/@TVQ/@TVR 回复格式保留。旧 @TVC/@TVD 只允许模式字段等于当前模式，更新对应速度参数并保留新增 Kd；模式字段不一致整包拒绝。旧 @TC 仅更新位置周期，现仅允许停机。ARM1、TRJ1 与普通遥测格式保留；四种轨迹须速度模式且交接完成，普通移动支持两种外环。

任务 CSV 增加位置 Kp/Ki/Kd、速度 Kd、实际模式和交接剩余时间，配置 JSON 同时保存两组参数。既有 `position_kpos` 列表示速度模式中的位置修正 Kpos，不属于位置 PID 参数组。任务速度记录在停机或断线后结束，后续调参和重连回读不会混入旧任务。普通 10 列 CSV 保持兼容，因此仅凭普通 CSV 不能直接确认模式和增益。

## 验证和交付

为满足 50 MHz 时序，板级 PID 乘法、求和、限幅分拍计算；角度内环仍用原编译增益和离散算法，积分／微分历史的采样时刻不变，结果多 2 个 50 MHz 时钟（40 ns），角度补偿同步对齐。轨迹共享乘法器和遥测格式换算也增加寄存阶段；1 ms 轨迹节拍、5 ms 角度周期与数值格式不变。

验证包括两组参数双向隔离及实际输出、K1/K3 强制位置、K2 仅空闲有效／不排队、内环历史和目标坐标保留、200 ms 交接与 t 渐增、X/K4／故障中断、D 时间尺度／滤波／首样本／饱和／溢出、四种轨迹和旧协议、网页只读模式显示／停机应用／草稿／重连。最终 RTL 54/54、网页 11/11、浏览器验证通过。50 MHz 下 Fmax=50.225 MHz，建立／保持违例 0/0，最差裕量 0.090/0.211 ns；完整记录见本次发布目录及 test-record.md。

下载文件不自动烧录，数字仿真不代表实物过冲已改善。保留已有中心标定、角度内环及历史发布包；实际增益与过冲需采集含模式、两组参数和反馈速度的新数据验证。
