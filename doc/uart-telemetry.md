# 网页角度与 PWM 数据回传

2026-10-17：当前固件使用 **55 字节**，在原角度和两路 PWM 后增加转臂累计位置、位置目标、连续位置误差、目标倾角偏移四个字段；网站包含对应读数、曲线及十列 CSV。位置与误差已取消每圈取模，当前语义见 [连续累计位置](continuous-position.md)，完整帧格式见 [历史扩展格式](circular-position.md)。当前构建结果见 [验证记录](test-record.md)。下文 31 字节帧和旧发布文件属于原 PWM 回传版本。

对应本机网页 <http://localhost:8765/> 的 `telemetry-core.js` 解码格式。打开网页，连接板载 USB 串口，选择 **115200、8N1、无流控**，点击「开始回传 P」。

- `P`：从序号 0 开始回传；已在回传时重复 P 不重置序号。不会启动电机。
- `Q`：停止产生新帧，已开始的完整帧发送完再停止。不会停止电机。
- `S/X/C/D/A`：继续分别执行原有起摆、停机、故障清除、ADC 原值显示、角度显示。
- K4 复位控制及电机，回传继续；板卡总复位 `rst_n` 会关闭回传。

## 数据格式

每 5 ms（200 Hz）同时锁存角度、要求 PWM 和实际 PWM，发送 31 字节 ASCII：

```text
T,00000000,-012.3,+0500,+0120\r\n
```

这里 `\r\n` 表示实际 CR/LF 字节 `0D 0A`。

| 字段 | 格式及来源 |
| --- | --- |
| `T` | 回传帧标记 |
| `00000000` | 32 位十六进制序号，8 位大写，溢出后自然回绕 |
| `-012.3` | `±DDD.d`，单位度；直接使用数码管 `angle_tenths`，保留现有 16 次 ADC 平均、零点和换算；D 原值显示模式不改变回传角度 |
| `+0500` | `±DDDD`，控制要求的有符号 PWM 计数，取当前送入 PWM 模块的请求并还原 MOTOR_INVERT 接线翻转 |
| `+0120` | `±DDDD`，PWM 模块实际执行的有符号占空比计数，包含缓升/缓降、换向死区、驱动禁止；同样还原接线翻转 |

当前参数为 50 MHz / 20 kHz，100% 对应 **2500** 计数。网页按 `计数 × 100 / 2500` 转成百分比。两种 PWM 使用控制器方向符号；`MOTOR_INVERT=1` 时物理引脚方向相反。若改变时钟或 PWM 频率，需要同步调整网页的 `PWM_MAX`。

实际 PWM 不是某一时刻的 PWM 高低电平，也不是电流或测速值。唤醒等待、复位、停止、故障或换向零占空比期间，实际值为零；换向缓降期间可与要求值方向相反。要求与实际通常会因缓升/缓降而不同。

## 时序与有效性

P 后首个采集时刻在 5 ms 后。每个采集时刻都递增序号；角度无效（平均值尚未建立、ADC 未就绪、传感器故障或 ADC 位于端点）时不发送，网页据序号缺口反映间隔。若低波特率使发送忙，也跳过该时刻，不排队发送旧数据。默认 115200 下每帧约 2.70 ms，可容纳 200 Hz。

串口全双工接收始终工作。帧转换、发送及最后停止位期间禁止命令回显，避免回显插入一行数据；帧之间保持原有空闲时回显。Q 可能在收到后约一个帧时长内仍收到最后一行，低波特率下等待更长。
