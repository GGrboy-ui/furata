# 速度模式静摩擦补偿 t（VEL2，2026-10-31）

## 设置与含义

运行本工程 `web/start.cmd`，使用窗口打印的网址；当前页面为 http://localhost:8767/。页面顶部标记“VEL2 / 位置启动”，速度参数区新增“静摩擦补偿 t（PWM 计数）”。

- 上电仍默认位置外环，t 默认 0（关闭）。t 是非负整数，范围 0～板端 PWM_MAX；当前 50 MHz、20 kHz PWM 下为 0～2500。1 个计数对应约 0.04% 占空比，t=25 对应额外 1 个百分点。
- t 输入框可先编辑待应用值，断线、运行或尚未识别时也可填写。按 X/K4 停机、连接并读到 VEL2 配置后，点击“仅应用 t（停机）”，只改变 t，保留板端当前 PI、周期和外环模式。若同时调节其他速度参数，可用原整组应用按钮。以板端回读为准，编辑输入框本身不会更改板端。
- 运行中（包括平衡空闲）拒绝修改。X/K4 停机并保留 t；重新上电或系统复位恢复 t=0。串口重连只读取板端配置。
- 旧 VEL1 固件保持原速度参数功能，t 可填写待应用值，实际下发按钮禁用并提示需 VEL2。旧 TRJ1／ARM1／普通遥测及普通 CSV 格式保留。

## PWM 路径

速度外环与角度内环计算不变。额外补偿在控制器输出转换为 PWM 计数后、原电机缓升和换向控制前加入：

```
base = floor(abs(controller_percent_q) * PWM_MAX / (100 * 65536))
if speed_outer && BALANCE && controller_percent_q != 0:
    magnitude = min(PWM_MAX, base + t)
else:
    magnitude = min(PWM_MAX, base)
pwm_control = sign(controller_percent_q) * magnitude
```

方向跟随实际控制输出，包括制动方向；编码器方向、电机接线反相和原保护继续沿用。控制器精确输出为零时不注入 t；非零输出即使量化不足 1 个 PWM 计数，也可加入 t。位置模式、起摆和电机固定 PWM 测试不叠加此补偿。

这是速度模式下持续的库仑摩擦偏置，不是一次性启动脉冲。它并不直接测量静摩擦，也不保证所填 t 恰好抵消机械摩擦；t 需在实物上调节，过大可使往返或终点保持振荡。

实现采用 17 位加法避免溢出，并在最终输出处限幅。PWM 转换、加法、饱和分别寄存，相比原路径额外增加两个系统时钟（50 MHz 下 40 ns）；X、故障、K4 的电机禁止仍为原即时门控，原缓升与换向死区继续生效。普通 PWM 遥测中的 requested 已包含 t，actual 仍为驱动器最终实际值。

## 串口兼容扩展

旧接口原样保留：`@TVI` 返回 VEL1 能力，`@TVQ` 返回原 98 字节 @V 状态，`@TVC,id,outer,period,kp_q,ki_q,kpos_q` 保留已有 t、不修改它。

新增 LF/CRLF 结尾的 ASCII 请求：

```
@TV2                                      查询 VEL2 能力
@TVR                                      查询包含 t 的配置与反馈
@TVD,id,outer,period_ms,kp_q,ki_q,kpos_q,t   停机原子设置（t 为整数 PWM 计数）
@TVD,1,1,20,6554,1311,32768,25             设置速度模式及 t=25
```

能力回复为 `@I,VEL2,0014,0005,0064,09C4` 加 CRLF（29 字节），最后字段是当前 PWM_MAX 的四位十六进制，不能假定测试或其他时钟配置总为 2500。

新增 @V 回复在原 elapsed 字段后追加 `,t4`，总长 103 字节，所有原字段保持位置与单位，t 为四位无符号十六进制 PWM 计数。请求编号及结果仍为 04 生效、11 状态不允许、12 参数超界。超界、非法格式或 X 中断不会部分修改模式／PI／t。t=0 有效，负数和小数无效。

网页先识别 VEL1，再探测 VEL2；识别后使用 @TVR/@TVD。任务 CSV 最后一列新增 `friction_t_pwm_counts`，配置 JSON 同时保存 `frictionT`，普通 CSV 不变。
