使用说明

通过板载 USB 串口连接。P 开始回传，Q 仅停止回传；S 起摆、X 停机功能保持原样。转臂位置以进入平衡时为零点，默认每 408 个计数一圈；误差采用最短方向。

数据来源

角度保持显示平均。实际 PWM 表示 FPGA 执行的占空比。目标倾角偏移由位置环产生，以当前 333° / 4095 ADC 标称比例换算。旧固件或旧文件缺少的字段显示为空值。
