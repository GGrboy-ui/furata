## 使用构建复用

在本工程目录执行：

```powershell
.\run_gowin.ps1
```

脚本比较实际源码、工程文件、约束、构建脚本、工具标识、实现配置，以及已有网表／下载文件／时序报告哈希；全部一致且时序通过时直接复用结果。高云 GUI 的“全部运行”仍执行完整流程，该复用只适用于上述脚本。

```powershell
# 强制完整综合和布局布线
.\run_gowin.ps1 -ForceRebuild
# 仅检查综合，不生成新下载文件
.\run_gowin.ps1 -ProcessName syn
# 先有本脚本当前输入的有效综合记录，才能单独运行布局布线
.\run_gowin.ps1 -ProcessName pnr -ForceRebuild
```

首次构建、修改 RTL／约束／实现选项、输出文件改变或工具变化后仍需重新构建。脚本不会自动烧录；同时通过本脚本构建同一目录会被锁阻止，不同目录使用各自 TCL，历史日志保留。编译过程中源码改变、工具失败、没有新输出或出现时序违例时，不记录新的成功复用结果。

最终综合警告、仿真、时序、完整构建与复用实测结果见 `build/warnings_build_cache_20261031/release/`。
