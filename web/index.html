2 · 每次只执行一个短试验

每个新方向及 PWM 先做短电流预检，再登记峰值和 VM 最低值。长测试开放条件：电机引线峰值 ≤ min(0.8 A, 电机允许值)，VM 最低值 ≥ 95% 静态 VM。外部波形记录不能作为实时过流保护。到 20% 仍不可靠起动就停止排查，不继续提高 PWM。

使用说明

通过板载 USB 串口连接。P 开始回传，Q 仅停止回传；S 起摆、X 停机功能保持原样。转臂位置以进入平衡时为零点，默认每 408 个计数一圈；误差采用最短方向。校准会话期间普通 P/Q 采集入口暂停，断开先停机。

数据来源

角度保持显示平均。实际 PWM 表示 FPGA 执行的占空比。目标倾角偏移由位置环产生，以当前 333° / 4095 ADC 标称比例换算。旧固件或旧文件缺少的字段显示为空值。校准使用未回绕位置与原始 ADC，100 Hz M/R 帧带 CRC。
