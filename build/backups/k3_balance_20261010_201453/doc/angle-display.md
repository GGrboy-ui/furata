## 八位显示格式

从左到右：**状态、故障、空白、符号、百位、十位、个位及小数点、小数位**。正数的符号位为空白，负数显示 `-`，保留一位小数。

| 显示示例 | 含义 |
| --- | --- |
| `00  000.0` | 停止、无故障、0.0° |
| `00 -090.0` | 停止、无故障、−90.0° |
| `40  012.3` | 平衡控制状态、无故障、+12.3° |
| `60  012.3` | 固定方向、20% PWM 试转状态、无故障、+12.3° |
| `54 -----` | 故障状态，故障码 4；角度无效 |
| `00  1014` | 原始 ADC 模式，平均采样值 1014，右侧没有小数点 |

表中的空格也是一个数码管位置，小数点不占额外位置。显示使用 16 次采样平均以降低跳字，每次采样 1 ms；控制器仍使用原始 ADC 数据，显示平均不会改变控制环采样路径。数码管逐位扫描约 1 kHz，完整八位刷新约 125 Hz。

| 左起第 1 位 | 控制状态 |
| --- | --- |
| 0 | STOP：停止 |
| 1 | PUSH：第一段起摆脉冲 |
| 2 | PULL：反向起摆脉冲 |
| 3 | WAIT_PEAK：等待摆杆位置满足条件 |
| 4 | BALANCE：平衡控制 |
| 5 | FAULT：故障停机 |
| 6 | MOTOR_TEST：固定 PWM 开环试转，默认 20% |

| 左起第 2 位 | 故障含义 |
| --- | --- |
| 0 | 无故障 |
| 3 | 超过约 5 ms 没有完成 ADC 采样 |
| 4 | 连续约 500 ms 采样为 0 或 4095 |
| 5 | ADC 帧超时，或平衡状态角度超出捕获范围 |
| 6 | 起摆超过 15 s 未进入平衡 |
| 7 | 转臂位置超过设置的范围 |
| 8 | 控制状态非法 |

故障 5 根据触发路径区分来源，当前显示未将它拆成两个代码。修复故障条件后，按 K4 可停止并清除锁存，也可串口发 `X` 停止、发 `C` 清除锁存，再启动。持续存在的传感器故障在 K4 复位后仍会重新锁存并禁止输出，不能靠按键屏蔽故障。单次轨端采样也会立即令角度显示为横杠；原始 ADC 模式保留读数用于检查接线。横杠不能检测电位器所有机械盲区，也不能证明传感器断线。

## 串口命令

使用板卡已有 UART 通道，**115200 波特率、8 数据位、无校验、1 停止位**，发送大写 ASCII 字符（关闭 HEX 发送）。

| 字符 | 十六进制字节 | 功能 |
| --- | --- | --- |
| `A` | 41 | 显示角度（复位默认） |
| `D` | 44 | 显示十进制原始 ADC 平均值 0000～4095 |
| `S` | 53 | 启动起摆 |
| `X` | 58 | 停止 |
| `C` | 43 | 停止状态下清除已消失的故障 |

`A`/`D` 只切换显示，不启动电机；串口仍回显正确接收的字符，没有新增串口角度上传协议。模式切换断电后不保存。当前按键为：K1 起摆，K2 从停止状态启动固定 20% PWM 试转，K3 在平衡状态减小 10° 位置目标，K4 停止并复位控制。K4 保留 A/D 显示模式和传感器标定。详细步骤见 [电机试转说明](motor-test.md)。

## 角度换算与标定

当前按套件手册的 SV01A103AEA01R00 电位器配置，其机械可转范围为 360°，有效电气范围标称 **333°**。显示是有效电气区间内相对零点的角度，不是连续多圈角度。

默认以竖直向上为 0°。当前零点 `1014` 来自用户于 2026-10-09 确认的直立、静止实测值；此前参考值为 2098。重新安装传感器后，应重新核对该姿态的 ADC 数值。

在 `src/board/acg720_top.v` 顶部设置并重新编译下载：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `CENTER` | 1014 | 控制器的直立中心，用户确认的实测值 |
| `ANGLE_ADC_ZERO` | `CENTER` | 仅显示零点，默认跟随控制中心 |
| `ANGLE_ADC_SPAN` | 4095 | 跨越标称电气角度时对应的 ADC 差值 |
| `ANGLE_RANGE_TENTHS` | 3330 | 标称电气角度，单位 0.1° |
| `ANGLE_INVERT` | 0 | 设为 1 可反转显示正负方向；不改变控制器方向 |

换算关系为：

```text
角度[°] = (平均ADC − ANGLE_ADC_ZERO) × 333.0 / ANGLE_ADC_SPAN
ANGLE_INVERT=1 时取相反数；按 0.1° 四舍五入。
```

推荐的两点标定步骤：

1. 串口发 `D`，把摆杆固定在竖直向上，记录稳定读数 `A0`。将 `CENTER=A0`，保持 `ANGLE_ADC_ZERO=CENTER`。
2. 在同一连续有效区间内转到已知的 **+90°** 姿态，记录 `A90`。按 `round(abs(A90-A0) × 333 / 90)` 设置 `ANGLE_ADC_SPAN`；`A90>A0` 时设置 `ANGLE_INVERT=0`，反之设置为 1。
3. 重新编译、下载后检查 0°、+90°，再用 −90° 姿态复核。两点不能跨过电位器电压跳变/盲区。当前参数适用范围为 ZERO=0～4095、SPAN=1～4095、RANGE_TENTHS=1～3600。

若需要自然下垂为显示零点，只修改 `ANGLE_ADC_ZERO` 为该姿态的 ADC 值；控制器 `CENTER` 仍必须保留直立中心。供电与 ADC 参考电压不完全相等时，标称 SPAN=4095 也会产生比例误差，因此绝对角度要靠标定。显示一位小数代表分辨格式，不代表实物精度达到 0.1°。
