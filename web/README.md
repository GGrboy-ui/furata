# 角度与有符号 PWM 回传

网页从串口接收 FPGA 已用于数码管显示的角度值。发送 `P` 开始，每 5 ms 一帧；发送 `Q` 仅停止回传。`S` 保持起摆功能，`X` 停机并关闭回传。普通采集按钮只发送 P/Q。2026-10-14 新增独立电机死区实测区，使用同一 Web Serial 连接和独立的 100 Hz 校准帧。

## 使用

1. 将重新编译的 `G:/furata/furata/impl/pnr/furata.fs` 下载到板卡。
2. 双击本目录的 `start.cmd`，或在 PowerShell 执行 `./start.ps1`（需要 Python）。
3. 在桌面 Chrome / Edge 打开 <http://localhost:8765>。串口访问采用 [Web Serial API](https://developer.chrome.com/docs/capabilities/serial)，需要浏览器支持及安全上下文；localhost 可用于本地运行。Codex 内嵌浏览器可预览或导入文件，实物采集请使用桌面 Chrome / Edge。
4. 关闭占用该 COM 口的串口助手，点「连接串口」，选择板载 USB 转串口；默认 115200 / 8N1 / 无流控。
5. 点「开始回传 P」。电脑数值直接来自 `angle_display_data.angle_tenths`，与数码管的正负方向、一位小数、现有 16 次采样平均一致。
6. 在「曲线」选择「要求 / 实际 PWM」查看两条曲线。可暂停绘图、切换时间范围、导出 CSV 或导入本网页导出的 CSV / 原始串口文本。Q 不改变电机控制状态，断开串口前网页也会发送 Q。

用 `Ctrl+C` 停止本地服务器。需要更换端口时执行 `./start.ps1 -Port 8766`，并打开对应 localhost 地址。页面不依赖外部 CDN，采集数据只在浏览器内存中保存；刷新/关闭前请导出。

## 数据协议

2026-10-12 新版增加位置回传，帧长为 55 字节：

```text
T,00000000,+000.2,-0069,-0069,+0012,+0000,-0012,-0125\r\n
```

最后四项分别为相对平衡原点的一圈位置、位置目标、最短位置误差（均为整数 counts），以及位置环产生的目标倾角偏移（单位 0.1 ADC code）。例如 -0125 表示 -12.5 ADC code，按当前 333°/4095 ADC 换算约 -1.016°。网站新增位置和目标倾角偏移读数、两类曲线，CSV 增加四列；旧记录缺少字段时显示空值。默认一圈 408 counts；修改固件标定时同步 `telemetry-core.js` 的 `COUNTS_PER_REV` 与角度换算常量。

新版默认 115200 下发送一帧约 4.77 ms，支持 200 Hz。下文 31 字节格式为兼容的历史版本。

```text
T,00000000,+012.3,-1250,+1000\r\n
T,00000001,-005.6,+0000,+0000\r\n
```

固定 31 字节 ASCII：`T` 标记、8 位十六进制 uint32 序号、带符号三位整数和一位小数的角度（°）、要求 PWM 和实际 PWM 的带符号四位整数计数，以真实 CR LF 结束。示例中的 `\r\n` 仅表示结束字节。第一帧在 P 生效后 5 ms 的发送期限生成，序号从 0 开始；网页将首个接收到的样本记为时间 0，后续按序号差 × 5 ms 还原时间，不使用电脑收到 USB 数据包的时间。

P 在已开启时重复发送不重置序号；Q/X 停止后再次 P 开启，序号重新从 0 开始。网页识别序号重启和 uint32 回绕，分段显示。不同采集段拼接为展示时间轴，段与段之间的等待时间不作为实物连续时间。

数码管角度无效（显示横杠）时不发送数值，但序号继续计时；恢复后曲线留下缺口。若波特率低到一帧无法在 5 ms 内发送，发送忙期间也会跳过该期限并保留序号缺口。默认 115200 下每帧约 2.69 ms，可满足 200 Hz。回传中禁止命令回显插入数据帧，Q/X 停止时会完成当前帧；RX 和控制保护不等待 TX。

16 次采样平均的角度通常每 16 ms 更新一次，因此 5 ms 回传的相邻值可能重复。这正是直接回传数码管值的结果，不代表原始 ADC 以 200 Hz 重新采样。`D` 切换数码管原始 ADC 模式时，回传仍是角度寄存器，恢复 `A` 可对照角度显示。

## 保留与导出

内存最多保留最近 120,000 个样本（连续 200 Hz 时约 10 分钟），到达上限会覆盖最早样本并提示；导出为当前保留部分。CSV 列为 `time_ms,sequence,angle_deviation_deg,session,pwm_requested_counts,pwm_actual_counts`，序号列使用十进制。RMS 基于当前保留样本计算，序号缺口可能来自无效角度、发送忙或通信丢失，不等同于纯串口丢包数。

## PWM 字段的含义

- 要求 PWM：顶层 `pwm_command`，已完成 MOTOR_INVERT 方向转换，尚未执行占空比斜坡和换向等待。
- 实际 PWM：`pwm_motor.applied_cmd`，按当前 `duty_q` 和 `dir_q` 给出有符号占空比计数。驱动禁止、停机或故障时立即为 0，即使内部占空比寄存器尚未清零。
- 两项与角度在同一个发送期限采样；只在遥测模块中转换为文本，不改变 PID、电机驱动或保护路径。
- 当前 PWM_MAX=2500（50 MHz / 20 kHz），计数 / 25 = 占空比百分比。CSV 保存精确整数计数，网页显示百分比；两条曲线使用相同符号约定。
- 实际 PWM 是 FPGA 执行的占空比，不能直接解释成电机电流、力矩或机械转速。驱动芯片和电源之后的响应仍需测量。
- 网页兼容旧 19 字节角度帧和旧四列 CSV。旧记录的 PWM 留空，不补为 0。混合记录导出时也保留空值。
- 默认每 5 ms 回传仍为 200 Hz，可看出持续换向滞后；短于 5 ms 的过程不能靠这些离散点精确计时。

例如 `-1250,+1000` 表示要求 -50% PWM、实际仍在 +40%，可用于识别换向期间尚在原方向降幅的情况。

## 电机死区实测

连接后网页发送 `!i\n` 查询能力。只有校验正确的 `DZCAL1` I 帧才开放校准入口；普通采集继续兼容旧固件。构建清单 `calibration-manifest.json` 可自动读取或手动载入，构建 ID 及源码/位流哈希随报告保存。清单不能替代板端握手；缺失或 ID 不匹配会明确标注。

1. 摆杆自然下垂，先确定 CPR、实际转向、编码器所在轴及实体行程。填写额定电压、实测 VM、电机允许电流和仪器信息。CPR 范围 64～65535，原点两侧行程 0.5～15°，必须容纳至少两个计数。
2. 建立会话发送 X → Q → !i → !c。校准旁路平衡控制；会话期间冻结条件及行程原点，普通 P/Q 按钮禁用。只有 M 帧确认会话、输出归零并停机至少 1 秒，才允许下一次测试。
3. 每个新方向/PWM 先做短预检（全程不超过 20 ms，实际非零最多 8 ms）。用示波器记录单根电机引线峰值电流和 VM 最低值：电流须 ≤ min(0.8 A, 电机允许值)，VM 须 ≥ 静态值的 95%。未通过会结束会话；电源侧平均电流不能代替绕组峰值。外部记录不是 FPGA 实时过流保护。
4. 起动粗扫从 1% 开始，以 1 个百分点调整；边界改为 0.2 个百分点。点击“只更新候选档”不会启动电机；每次测试均需用户点击。20% 仍不能可靠起动时停止排查。起动同向进展达到两码停止，观察最多 100 ms，全程最多 120 ms。
5. 登记转臂是否实际动作。只有电机轴空转不算成功；板端判据与实际动作矛盾时记无效。每方向边界档位至少收集 5 次有效重复，以最低的全部成功档位作为 D_start；相邻低档失败记录用于闭合门槛区间。
6. 维持测试的起动 PWM 固定取同方向已验证 D_start + 1 个百分点，并要求独立电气预检。目标 PWM 可降到 0，零档无需电流预检；正反零档分别记录。去掉 100 ms 过渡后观察三个 100 ms 窗口，整个测试不超过 600 ms；人工确认的是**维持观察阶段**的持续转臂运动。零输出基准仍可能含惯性，D_run 仅适用于本观察时长。
7. 在另外两个安全转臂位置重新建立会话复核，使用不同“位置标识”。每次新会话使用新 ID 与新原点，预检不能跨会话复用。导出原始校准 CSV、试次汇总 CSV 和可离线打开的 HTML 报告；刷新页面前保存文件。

网页每 50 ms 发送心跳，FPGA 200 ms 超时停机。保持网页前台；校准数据超过 250 ms 未更新时网页主动发送 X 并将当前试次记无效。板端固定试次期限独立于心跳，失联不延长输出。校准退出或断开先 X、退出会话、Q；普通角度采集断开仍只发 Q。

缓存查询先 !i 再 !g，仅查询板端最后结束试次，不能重启电机。进行中的 R（pending/无结束时间/试次 0）不锁存为结果；数据缺口、故障、行程中止及未人工确认试次不进入可靠门槛统计。校准原始记录和普通 5 ms Recording 完全分开，校准 CSV 不套用旧数据的 5 ms 时间假设。

本页不改变补偿量或 PID。D_start 用于后续短时起动补偿参考，D_run 用于运行量级参考；摆杆被动转轴静摩擦仍需单独处理。完整实验与下载说明见 `../doc/motor-deadzone-calibration.md`。
