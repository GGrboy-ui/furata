# 一圈位置归零与位置环回传

**历史实现：2026-10-17 已取消位置环的一圈归零，当前行为见 [连续累计位置反馈](continuous-position.md)。下文保留旧环形算法、串口字段语义及历史构建记录。**

当前修订（2026-10-13）：保留环形位置反馈和位置 PID 的 D 项，已删除独立转臂速度阻尼。平衡区间新增 [线性 PWM 补偿](balance-pwm-boost.md)；当前位置只通过既有位置环修正角度目标，不再叠加编码器位移差分的 PWM 修正。本文末尾的 2026-10-12 下载文件和实现数据为历史记录，最新结果见 [验证记录](test-record.md)。

2026-10-12：位置环改为环形角度反馈。默认 `COUNTS_PER_REV=408`，必须对应减速后转臂一圈的四倍频计数；应以手动转一圈的 RAW 差值校准。

按 K3 时仍捕获转臂当前位置为原点，目标相对位置为 0。现在位置环使用最短位置误差：

```text
relative = wrap(position - origin)
error    = wrap(target - (position - origin))
wrap 的范围 = [-COUNTS_PER_REV/2, COUNTS_PER_REV/2)
```

默认一圈 408 counts 时，相对位置为 -204～203：移动 +408 或 -408 counts 后均归零；+409 为 +1，+407 为 -1。半圈两侧的反馈按最短方向处理，位置 PID 的微分也使用环形差值，避免跨过 203/-204 时产生约 408 counts 的微分冲击。目标中的整圈数同样被取模，此控制模式保持方位，不执行额外的整圈轨迹。

环形余数用顺序除法求出，正常新计数约 53 个系统时钟后发布，远短于 1 ms 采样和 50 ms 位置环周期。保留 Q16.16 的小数目标和小数误差。当前位置不会用于独立速度阻尼；转臂位移仍用于位置环和累计行程保护。

OLED 显示：RAW 为原始累计计数；POS 为按反馈方向修正后、相对上电零点的一圈坐标；REL 为相对平衡捕获原点的一圈坐标。POS 和 REL 每圈回到同一数值，RAW 继续累计。K4 保留编码器 RAW/POS，重新复位控制原点。累计位移保护仍使用原始行程；默认超过捕获原点 ±10 圈仍触发故障 7，不会被位置取模掩盖。

串口使用 55 字节帧，每 5 ms 对所有字段取快照：

```text
T,00000000,+000.2,-0069,-0069,+0012,+0000,-0012,-0125\r\n
```

| 字段 | 示例 | 单位及含义 |
|---|---:|---|
| 序号 | 00000000 | 十六进制序号，5 ms 一次 |
| 摆杆角度 | +000.2 | 数码管平均角度，° |
| 要求 / 实际 PWM | -0069 / -0069 | 有符号 PWM counts，2500 对应 100% |
| 转臂位置 | +0012 | 相对捕获原点的一圈位置，counts |
| 位置目标 | +0000 | 相对原点的目标，counts；当前 K3 为 0 |
| 位置误差 | -0012 | 目标减实际的最短误差，counts |
| 目标倾角偏移 | -0125 | **0.1 ADC code**，这里为 -12.5 ADC；不是 -12.5° |

目标倾角偏移来自 `-position_out`，也就是角度环目标相对 `CENTER` 的偏移。网站按 `ADC偏移 × 333 / 4095` 转换为度，示例约 -1.016°。这与当前数码管比例一致；改变标定比例或显示方向时，须同步网站 `telemetry-core.js` 的换算。网站用 3 位小数显示，原始回传分辨率为 0.1 ADC code。位置和目标误差的回传取整到 counts；控制内部仍保留小数。

55 字节在 115200、8N1 下约占 4.77 ms，已用实际 UART 位流仿真验证连续 200 Hz 无序号缺口。更低波特率会跳过发送忙时的采样期限，缺口在网站显示。P/Q 与电机命令的语义保持不变。

网站 <http://localhost:8765/> 新增当前位置、位置目标、位置误差和目标倾角偏移读数，并新增两种曲线：“转臂位置 / 目标 / 误差”、“角度 / 目标倾角偏移”。圈边界不连接成虚假的大位移直线。CSV 新增 `arm_position_counts,position_target_counts,position_error_counts,angle_target_offset_adc` 四列。兼容旧角度帧、旧 PWM 帧和四列/六列 CSV；旧记录缺少的位置字段保持空值。
