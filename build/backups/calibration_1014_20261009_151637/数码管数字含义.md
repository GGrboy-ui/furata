# ACG720 数码管数字含义

整理日期：2026-10-09  
适用工程：`G:/furata/furata/furata.gprj`，顶层 `acg720_top`，已加入板载八位数码管角度显示的版本。

**最左侧第一位表示运行状态，第二位表示故障码，右侧表示角度或 ADC 原始读数。前两位不是角度的一部分。**

## 1. 八位数码管的位置

面对数码管，从左向右编号为第 1～8 位。

| 位置 | 角度模式（默认） | ADC 原值模式 |
| --- | --- | --- |
| 第 1 位 | 运行状态 | 运行状态 |
| 第 2 位 | 故障码 | 故障码 |
| 第 3 位 | 空白，用于分隔 | 空白 |
| 第 4 位 | 负数显示 `-`，正数为空白 | 空白 |
| 第 5 位 | 角度百位 | ADC 千位 |
| 第 6 位 | 角度十位 | ADC 百位 |
| 第 7 位 | 角度个位，右侧小数点亮 | ADC 十位，小数点不亮 |
| 第 8 位 | 角度小数位 | ADC 个位 |

角度模式布局：

```text
位置：  1     2     3     4     5     6     7     8
含义： 状态  故障  空白  符号  百位  十位  个位  小数位
                                           ↑
                                      小数点在个位右侧
```

例如 `00 -090.0` 表示状态 0、故障码 0、角度 −90.0°。其中空格也是数码管位置；小数点附着在第 7 位，不占额外位置。角度单位为度，保留一位小数。

## 2. 第 1 位：运行状态

| 数字 | 程序状态 | 含义 |
| --- | --- | --- |
| 0 | STOP | 停止，电机使能关闭；传感器仍采样并刷新显示 |
| 1 | PUSH | 第一段起摆脉冲，默认目标为 35% 占空比，持续约 100 ms |
| 2 | PULL | 反向起摆脉冲，默认目标为 35% 占空比，持续约 100 ms |
| 3 | WAIT_PEAK | 等待角度历史数据满足捕获条件或下一次起摆脉冲条件；该状态下电机指令为零 |
| 4 | BALANCE | 平衡控制，控制器根据角度和转臂位置计算电机指令 |
| 5 | FAULT | 故障停机，电机输出被禁止 |

这里的状态表示**程序正在执行的流程**，不能单凭状态数字判断电机实物已经转动、摆杆已经起摆或机械系统已经稳定平衡。

正常启动时可能看到 `00 → 10 → 20 → 30`，满足捕获条件后进入 `40`。前两段各约 100 ms，肉眼可能看不清，可以用手机录像观察。未满足条件时，程序可能等待、再次输出起摆脉冲，或最终故障停机。

## 3. 第 2 位：故障码

| 数字 | 含义 | 当前程序的触发条件 |
| --- | --- | --- |
| 0 | 无故障 | 没有当前故障或已锁存故障 |
| 3 | ADC 采样超时 | 约 5 ms 内没有完成采样 |
| 4 | ADC 持续处于量程端点 | 连续 500 个采样值为 0 或 4095，按 1 kHz 采样约为 500 ms |
| 5 | ADC 帧超时，或平衡时角度超出范围 | ADC 一帧处理持续约 5 ms；或者平衡状态下采样值离开控制中心的捕获窗口 |
| 6 | 起摆超时 | 运行过程中超过约 15 s 尚未进入平衡 |
| 7 | 转臂位置越界 | 相对启动位置的编码器计数超过配置限制，默认 ±4080 个计数 |
| 8 | 控制状态异常 | 控制状态不在合法范围内 |

当前版本未使用故障码 1、2。故障码 5 的两个来源共用同一个数字，不能仅凭 `55` 区分具体来源。

控制中心默认 `CENTER=2098`，捕获窗口为中心两侧各 500 个 ADC 数值。按当前严格比较条件，窗口内有效整数值为 **1599～2597**。这些是 ADC 数值，不是角度；修改标定参数后，应按新参数理解范围。

显示使用平均值，控制器使用原始采样。因此，显示看起来平稳不能排除原始采样曾短暂超出范围。

## 4. 常见组合与示例

| 显示 | 如何理解 |
| --- | --- |
| `00  000.0` | 停止、无故障，角度为 0.0° |
| `00  012.3` | 停止、无故障，角度为 +12.3° |
| `00 -090.0` | 停止、无故障，角度为 −90.0° |
| `10  012.3` | 第一段起摆脉冲、无故障，当前角度 +12.3° |
| `20  012.3` | 反向起摆脉冲、无故障，当前角度 +12.3° |
| `30  012.3` | 等待捕获或后续脉冲条件、无故障，当前角度 +12.3° |
| `40 -005.6` | 平衡控制、无故障，当前角度 −5.6° |
| `54 -----` | 故障停机、故障码 4，当前角度无效 |
| `55  012.3` | 故障停机、故障码 5；当前角度仍有效，但电机输出被禁止 |
| `56  012.3` | 故障停机、起摆超时，当前角度仍有效 |
| `00  2098` | ADC 原值模式，停止、无故障，平均 ADC 读数为 2098 |

**`55` 不是 55°，也不是第 55 步；它表示状态 5 和故障码 5。**

## 5. 横杠表示什么

右侧出现连续横杠，例如 `00 -----` 或 `54 -----`，表示程序当前没有可显示的有效角度。

可能包括：

- 刚启动，尚未完成首组平均采样和换算。
- 当前传感器采集存在故障。
- 采样值或用于显示的平均值为 0 或 4095。

横杠表示“角度无效”，不是一个负角度。正常负角度只在第 4 位显示一个负号，后面仍有数字。

ADC 原值模式在已经得到采样数据后可以显示 `0000`、`4095`，便于检查输入是否处于量程端点。横杠不能检测传感器所有机械盲区，也不能单独证明传感器断线。

## 6. 串口切换与故障清除

使用板载 USB-UART，串口助手设为 **115200、8 数据位、无校验、1 停止位、无流控**。发送大写 ASCII 字符，关闭 HEX 发送和自动循环发送。

| 命令 | 功能 | 对数码管的影响 |
| --- | --- | --- |
| `A` | 显示角度 | 右侧显示正负角度，小数点亮；复位默认模式 |
| `D` | 显示 ADC 原值 | 右侧显示 0000～4095，小数点熄灭；前两位含义不变 |
| `X` | 停止 | 请求停止；不会自动清除故障锁存 |
| `C` | 清除故障 | 只在停止、且当前故障条件已消失时清除锁存 |
| `S` | 启动起摆 | 与 K1 的启动作用相同，仍受传感器就绪和故障许可限制 |

`A`、`D` 只切换显示模式，不启动电机。ADC 原值模式显示的是 **16 次采样平均后的 ADC 码**，未换算为角度。显示模式复位后恢复为角度模式，不会永久保存。

故障锁存意味着：**即使角度后来恢复正常，电机也不会自动重新启动。K1 不负责清除故障。**

遇到 `55` 等故障显示时：

1. 先单独发送 `X`，保持停止。
2. 排查并修复触发故障的条件。
3. 单独发送 `C`，观察前两位是否恢复为 `00`。
4. 恢复后先核对角度与控制中心，按需要再松开并重新按下 K1。

若故障条件仍持续存在，`C` 不能清除。如果恢复 `00` 后再启动又出现故障，应记录启动过程中的前两位变化，继续查明原因。

## 7. 显示零点与控制零点

角度显示默认以直立位置为零点，但当前默认 ADC 零点 `2098` 来自参考程序，需要按实际装配标定。

- `ANGLE_ADC_ZERO`：决定数码管显示的角度零点，默认跟随 `CENTER`。
- `CENTER`：决定控制器认为的直立中心。
- 仅修改 `ANGLE_ADC_ZERO`，不会改变控制器 `CENTER`。

因此，“显示角度准确”不等于“控制中心已经标定正确”。测量控制中心时，应保持电机停止，把摆杆固定在**竖直向上**，发送 `D`，记录稳定 ADC 原值。下垂位置不能代替直立控制中心。

显示保留一位小数是显示格式，不代表实际测量精度已经达到 0.1°。
