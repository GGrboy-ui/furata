# K2 电机试转与 K4 复位

更新：2026-10-10。实际下载工程为 `G:/furata/furata/furata.gprj`；下载文件为 `impl/pnr/furata.fs`。工作区中的旧参考工程 `G:/FPGA_furata/FPGA_Pendulum_ACG720` 未同步本次修改。

## 按键功能

| 按键 | 当前功能 |
| --- | --- |
| K1 | 从停止状态启动原来的自动起摆 |
| K2 | 从停止状态启动固定方向、20% PWM 试转；显示前两位 `60` |
| K3 | 停机时摆杆已在直立窗口内，直接进入持续平衡；详见 [K3 说明](manual-balance.md) |
| K4 | 停止电机并复位控制状态、故障锁存、PID、位置目标、PWM 和唤醒计数；无当前故障时显示 `00` |

试转是开环固定占空比，实际转速会随负载和供电变化。它不执行摆杆平衡控制，也不保证摆杆保持直立。K2 不会中断正在运行的起摆或平衡，也不能清除故障；切换到试转前先按 K4，再松开并重新按下 K2。

## 使用顺序

1. 在 Gowin Programmer 中选 GW5AT-60B / SRAM Program，下载新生成的 `impl/pnr/furata.fs`。本次软件修改没有自动烧录板卡。
2. 先保持停止，确认显示 `00`、传感器接线正常。K2 保留传感器就绪和故障许可条件。
3. 开启台式电源的限流功能，确认转臂可以运动，按一下 K2。试转保持固定方向；按 K4 停止。
4. K2 模式下 PWMA 稳态频率为 20 kHz，周期约 50 µs，高电平约 10 µs；启动沿先有 2 ms 电驱唤醒等待，随后占空比缓升至 20%。STBY 为高、AIN1/AIN2 一高一低。
5. K4 经原来的 20 ms 按键消抖后生效，电机使能和输出关闭。必须重新产生 K1/K2 按键事件才会再启动；长按 K2 不会在 K4 复位后自动重启。

串口 `X` 同样可以停止试转。K2 仍受相对启动位置 ±4080 个编码器计数的行程限制（按默认每圈 408 计数约为 ±10 圈）；越界进入故障。它不使用起摆超时，也不要求摆杆角度处于平衡窗口。持续传感器故障会在 K4 复位后重新锁存，电机保持关闭；应先修复故障，不能把显示强制为 `00` 来绕过关断。

20% 下没有转动不一定表示电机损坏，需要结合驱动输出和电流检查。先按 K4 停止，再检查；不要通过不断按启动键来判断。

## 可调参数

在 `src/board/acg720_top.v` 顶部修改后重新编译下载：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `MOTOR_TEST_PERCENT` | 20 | 试转 PWM 占空比百分数 |
| `MOTOR_TEST_REVERSE` | 0 | 设为 1 时反转试转指令方向，仍经过 `MOTOR_INVERT` |

当前用户调参为 `CENTER=1011`、起摆 45% / 120 ms；K3 修改保留这些设置。K4 不重置 ADC 采样、编码器原始计数、A/D 显示模式或角度显示；下一次启动会重新记录相对位置原点。
