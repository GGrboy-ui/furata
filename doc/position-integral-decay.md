# 位置积分近原点衰减

2026-10-29。控制入口为 `src/rtl/control_core.v` 的
`POSITION_I_DECAY_BAND_Q=131072`，即 Q16.16 的 ±2 个编码器计数。
按 408 counts/转计算，范围约 ±1.76°。范围以实时位置目标为中心，
使用现有的一圈最短位置误差；当前位置目标为零。

在每次位置 PID 更新时：

- 误差位于该范围内（包含边界）：不累加新误差，已有积分乘保留百分比，正负对称向零取整。
- 误差在范围外：恢复原来的积分累加和限幅，不恢复已经衰减掉的历史值。
- 范围参数设为 0 或负数：关闭衰减，恢复原有行为。
- KI 为 0、退出平衡或复位时仍按原有规则清除积分。

保留百分比在 `src/rtl/control_core.v` 中调整：

```verilog
parameter integer POSITION_I_DECAY_RETAIN_PERCENT=30
```

有效范围为 0～100，超出范围自动限制到最近边界。30 表示每次保留 30%、
去掉 70%；数值越小衰减越快。0 表示每次清零，100 表示保留全部已有积分，
但范围内仍不累加新误差；关闭整个衰减功能应把 `POSITION_I_DECAY_BAND_Q` 设为 0。
这是编译参数，修改后需重新编译、下载固件，不支持网页运行时调节。

默认位置环周期为 50 ms，保留百分比为 30。连续在范围内 50、100、150、200 ms
后分别保留约 30%、9%、2.7%、0.81%（实际定点运算会向零取整）。
改变 `POSITION_MS` 也会改变衰减的实际时间尺度。
该策略直接降低积分状态，而非只缩小输出或临时降低 KI。
P、D 在范围内仍正常工作；角度环未启用此衰减功能。
它不依赖速度门控，经过原点时也会衰减；其目的为提前释放位置积分。

保留用户现有 PID 增益。近原点的静态误差可能落在
±2 counts 内，实物需要检查残差与过冲的取舍。本次没有测定摩擦参数，
也没有上板验证机械响应。

专项测试：`tb_pid_integral_decay`、`tb_pid_integral_decay_percent`、`tb_control_integral_decay`。
覆盖双向衰减、范围边界、恢复累加、限幅、趋零残差、P/D 行为、
50 ms 更新节拍、目标变化、一圈回绕及停止/复位。
百分比测试覆盖 0、30、50、75、100、越界参数限制及最大积分乘法溢出检查。
