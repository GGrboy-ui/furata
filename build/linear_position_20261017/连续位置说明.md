# 连续累计位置反馈

2026-10-17：位置环取消一圈取模，采用相对捕获原点的连续累计计数。项目为 `G:/furata-git/furata/furata.gprj`。

```text
relative = position - origin
error    = target - relative
```

默认 `COUNTS_PER_REV=408`。K3 捕获当前位置为原点，目标为 0；相对原点正向转一圈，位置为 +408、误差为 -408；正向转两圈为 +816、误差为 -816。反向一圈为 -408、误差为 +408。只有回到捕获原点，目标为 0 时位置误差才归零。位置环会保持原来的累计位置，额外转过的整圈也会形成回位需求。实际回位效果仍取决于机械、反馈方向与 PID 调参。

位置 PID 的 D 项采用连续误差差值，不再启用 `DELTA_WRAP_Q`。跨过 ±半圈或整圈时，连续移动一个计数只产生一个计数的误差变化。控制内部保留 Q16.16 小数目标；误差超出有符号 32 位 Q16.16 数值范围时饱和，避免截位反号。默认 ±10 圈范围内不需要这种数值饱和。

行程保护继续使用未经取模或数值钳位的 `position-origin`，默认严格超过 ±4080 counts 时请求故障 7；恰好 ±4080 counts 不触发。该保护表示相对捕获原点的 **±10 圈净位移**，不是累计走过的路程。例如先正转 6 圈再反转 6 圈，净位移为 0，不会因为总路程 12 圈而触发。位置目标改变不会平移保护原点。

原点仍按原有操作捕获：K1 开始起摆时捕获一次，成功进入平衡时再次捕获；K3 只在停止且满足准入条件时捕获。运行中重复按 K3 不会重设原点。K4 停止并复位控制，保留原始编码器计数，控制原点复位为 0；下次启动再捕获。

OLED 三项均采用累计计数：RAW 为原始计数，POS 为经 `ENCODER_INVERT` 修正后相对上电原点的计数，REL 为相对控制捕获原点的计数。POS/REL 不再每圈归零。

串口仍使用原有 55 字节 T 帧、115200 波特率和 5 ms 取样周期；位置/目标/误差仍为整数 counts，目标倾角偏移仍为 0.1 ADC code。格式兼容，位置和误差的语义改为连续累计值。固定四位数字字段在绝对值超过 9999 时饱和；默认保护范围内足够使用。停止后大幅手动转动时，OLED 比串口保留更大的显示范围。网页标题和曲线同步采用累计位置，不再依据半圈幅值人为断线；序号缺口和会话边界仍断线。旧环形固件的 CSV 可以导入，但不会自动还原历史整圈数。

本次保留修改前已有的 `CENTER=1007`、`POSITION_KD=261072`，其余 PID 增益、采样周期和 PWM 参数也保持不变。较大偏移现在会保留回位误差，位置环输出仍受既有 ±100 ADC code 限幅约束。

专项测试位于 `sim/tb_control_position_linear.v`，覆盖正反整圈、多圈、返回原点、P/D 输出、小数目标、保护边界及数值饱和。OLED 板级测试通过真实 A/B 边沿检查跨圈计数；物理 UART 测试覆盖 +408/-816 counts，网页验证累计曲线连接及 CSV 往返。实际运行结果与独立构建输出见 [验证记录](test-record.md)。
