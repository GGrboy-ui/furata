# ±2° 线性 PWM 补偿

更新：2026-10-13。实际工程为 `G:/furata-git/furata`。平衡状态保留角度 PID 和位置 PID，在平衡中心附近增加线性 PWM 补偿；独立 `ARM_DAMPING` 速度阻尼已从当前代码删除，两个 PID 的 D 项仍保留。

## 行为

以顶层当前 `CENTER=999` 为固定中心，采用角度 PID 同一次 `angle_tick` 捕获的原始控制采样 `measured_angle_q`。补偿距离与位置环修正后的角度目标无关，显示用 16 点平均值也不参与补偿。位置环继续通过 `-position_out` 修正角度目标。

默认半宽为 24 个 ADC 码，令 `d=abs(ADC−CENTER)`，区间包含两侧边界：

```text
increment = 5 × d / 24           (0 ≤ d ≤ 24，单位为 PWM 百分点)
increment = 0                    (d > 24)
command = clamp(angle_PID + sign(angle_PID) × increment, -100, +100)
```

原角度 PID 输出为零时不添加补偿。补偿方向跟随原输出，包括 PID 正在反向制动时；不由偏角方向直接决定。内部使用 Q16.16 和加宽运算，补偿与同次角度 PID 结果同步发布，合成后才限幅。

| 距离 `d` | 默认 ADC 样例 | PWM 增量 |
|---:|---|---:|
| 0 | 999 | 0 个百分点 |
| 12 | 987 / 1011 | 2.5 个百分点 |
| 24 | 975 / 1023 | 5 个百分点 |
| 25 | 974 / 1024 | 0 个百分点 |

例如原输出 +10% 且 `d=12` 时要求值为 +12.5%；原输出 −10% 时为 −12.5%。每次控制更新根据同次采样判断区间，24 到 25 码的增量从 5 变为 0，边界跳变保留。串口要求 PWM 包含补偿；电机实际 PWM 继续受到既有 `PWM_SLEW_STEP` 渐变、换向等待和安全禁止约束。

仅在平衡状态应用补偿；K3 手动平衡和 K1 起摆捕获后共用此行为。起摆脉冲、等待捕获、K2 试转不叠加。退出平衡、停止、故障、失去许可及复位时撤掉补偿并清除待计算状态，K4 仍按原行为复位控制和 PWM。

## 综合参数

修改 `src/board/acg720_top.v` 中的参数后重新编译下载：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `BALANCE_BOOST_RANGE_TENTHS` | `20` | 半宽，单位 0.1°，20 表示 2° |
| `BALANCE_BOOST_MAX_PERCENT` | `5` | 边界最大增量，单位为 PWM 百分点 |

顶层按现有显示标定换算补偿区间：

```text
BALANCE_BOOST_RANGE_CODES = floor(BALANCE_BOOST_RANGE_TENTHS × ANGLE_ADC_SPAN / ANGLE_RANGE_TENTHS)
                         = floor(20 × 4095 / 3330) = 24
```

24 码按标称比例对应约 1.95°。控制核心通过 `BALANCE_BOOST_RANGE_CODES=24` 和 `BALANCE_BOOST_MAX_PERCENT=5` 接收参数；直接实例化核心时半宽使用 ADC codes。半宽或最大增量设为零时关闭补偿；负值按零处理，核心半宽最大为 4095 codes，最大增量钳在 0～100 个百分点。该区间与原捕获及角度保护窗口 `CAPTURE_RANGE=500` 分别配置；后者未缩小为 ±2°。
